# Calculation 1: finite-N operator-ensemble tests

This folder contains an exact-diagonalization test of the coupling-ensemble versus operator-ensemble statements in `../couplings-vs-ops.md`.

`syk_operator_ensemble_ed.py` uses the Jordan-Wigner representation of Majorana strings, stored compactly as phase-weighted permutations of the computational basis. It samples the `p=4` SYK Hamiltonian, computes thermal one-point functions
`xi(a) = tr(rho mu(a))` for every Majorana string of a chosen weight, and then measures

- the fixed-sample operator average `M1 = average_a xi(a)`,
- the fixed-sample operator second moment `M2 = average_a xi(a)^2`,
- the empirical disorder covariance/correlation between different strings,
- the empirical excess kurtosis of each string over the disorder ensemble.

```bash
/home/physicsmonkey/projects/levy-syk/.venv/bin/python syk_operator_ensemble_ed.py --n-values 8 10 12 --weights 4 --beta 1 --samples 120 --coupling-scale 4 --seed 20260607 --outdir outputs_beta1
```
