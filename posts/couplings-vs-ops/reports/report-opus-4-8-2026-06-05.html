Report on couplings-vs-ops.md

Reviewer: Claude Code (Opus 4.8) Date: June 5, 2026 Scope: correctness of the entry (couplings-vs-ops.md) and the supporting calculation-1 Verdict: Sound. The analytic claims are correct, and in one respect (exactness of the diagonal covariance) stronger than the entry states. The numerics reproduce, and the entry’s stated confidence (“High”) is justified. I flag one interpretive point about the M2 fluctuations that I think is worth sharpening, plus a few scope caveats. None of these are errors.

Summary of what I checked

  • Re-derived the four analytic moment results (M1 mean/variance, M2 mean/variance) by hand and confirmed them given the entry’s stated assumptions.
  • Examined the symmetry argument behind the diagonal covariance and concluded it is exact at finite N, not just leading-order in large N.
  • Reproduced the headline table from the stored data and re-ran two sizes from a fresh disorder seed.
  • Decomposed Var(M2) from the saved xi arrays into a marginal (single-string) part and a cross-string (joint) part, for both β=1 and β=4. This is the main new content of the report and it clarifies which assumption is responsible for the observed M2 deviations.

All re-runs used the project venv /home/physicsmonkey/projects/levy-syk/.venv/bin/python, which was present and working.

Section-by-section

Intro / motivation (unnumbered, lines 9–13)

No technical claims to check. The framing is consistent with the rest of the entry. Citations are placeholders ([cite], [cite de boer]), which is presumably intentional at this stage.

Setup (lines 15–27)

  • Normalization conventions (\{\psi_i,\psi_j\}=2\delta_{ij}, the Hermitian-phase string \mu(a), the SYK variance) are internally consistent and match the code. In syk_operator_ensemble_ed.py, sample_hamiltonian uses coupling_std = coupling_scale * sqrt(3! / N^3 / 2^4), i.e. exactly (p-1)!/N^{p-1}/2^p for p=4, times the deliberate coupling_scale factor.
  • \mathbb{E}_J(\xi(a))=0: correct. The cleanest one-line justification is a single-index reflection \psi_i\to-\psi_i for an i in the string: this is an O(N) element that leaves the J-measure invariant but flips \mu(a)\to-\mu(a), so \mathbb{E}_J(\xi)=-\mathbb{E}_J(\xi)=0. Numerically mean_m1 is \sim10^{-5}–10^{-4}, consistent with zero at the available statistics.
  • The remark that Z self-averages and the numerator/denominator can be averaged separately is used only in the analytic statements. The numerics instead use the exact ratio \rho=e^{-\beta H}/Z per sample (thermal_one_points), which is the more honest object, so there is no inconsistency.

Gaussian 1-point functions (lines 29–38)

The covariance claim \mathbb{E}_J(\xi(a)\xi(a'))=\delta_{a,a'}\,\sigma^2(W) is correct, and I think it is worth recording that it is exact at finite N, not merely a large-N statement. The matrix C_{ab}=\mathbb{E}_J(\xi(a)\xi(b)) is an O(N)-intertwiner on the space of weight-W Majorana strings, which is the exterior power \Lambda^W(\mathbb{R}^N). For W<N/2 this is an irreducible O(N) representation, so by Schur’s lemma C\propto \mathbb{1}, i.e. C_{ab}=\sigma^2(W)\,\delta_{ab} identically. (At the boundary case W=N/2, e.g. N=8,W=4, \Lambda^{4} splits into self-dual/anti-self-dual under SO(8) but the reflection in O(8) exchanges the two halves, so \Lambda^4 is still irreducible under the full O(8) and the conclusion holds.) The entry’s phrasing — “the precise identity of the string turns out not to matter” — is right; the symmetry argument actually delivers more than “only a function of weight,” it delivers exact orthogonality of distinct strings.

This is corroborated numerically: std(M1)/std_pred ≈ 1.00 across all N is precisely the statement that the linear cross-covariances vanish (otherwise the off-diagonal terms in \mathrm{Var}_J(M_1)=\tfrac{1}{D^2}\sum_{a,b}\mathrm{Cov}(\xi_a,\xi_b) would spoil the 1/D scaling). The measured mean absolute off-diagonal correlation \approx 0.025 matches the 1/\sqrt{1000}\approx0.032 sampling-noise floor, consistent with the true linear covariance being exactly zero.

Switching ensembles (lines 40–63)

I re-derived all four moment results and they are correct given the stated assumptions:

  • \mathbb{E}_J(M_1)=0. ✓ (linearity).
  • \mathbb{E}_J(M_1^2)=\sigma^2(W)/\binom{N}{W}. ✓ Uses only the diagonal covariance, which (per above) is exact. This result is therefore exact, not approximate.
  • \mathbb{E}_J(M_2)=\sigma^2(W). ✓ (linearity).
  • \mathbb{E}_J(M_2^2)=\mathbb{E}_J(M_2)^2+2\sigma^4(W)/\binom{N}{W} (line 62). ✓ but this one is exact only under full joint multivariate-Gaussianity. Writing D=\binom{N}{W}, the derivation needs both (i) \mathbb{E}_J(\xi_a^4)=3\sigma^4 (marginal Gaussian, giving the a=b terms) and (ii) \mathbb{E}_J(\xi_a^2\xi_b^2)=\sigma^4 for a\neq b (no connected cross-string 4-point cumulant). Assumption (ii) does not follow from the diagonal covariance: zero linear covariance does not imply \xi_a^2 and \xi_b^2 are uncorrelated. The entry is upfront that it is leaning on Gaussianity here (“The key feature is that \xi(a) is a Gaussian”), so this is a known approximation rather than a gap; I just want to name precisely which piece is the approximation, because the numerics below show it is the piece that actually fails.

Numerical tests (lines 68–98)

Reproduction. Every number in the table (lines 82–87) matches outputs_beta1_highstats/summary.csv to the quoted precision, e.g. N=8: std_m1_over_prediction = 0.968 and rel_std_m2_over_prediction = 1.523; N=18: 1.020 and 1.185. The kurtosis list (line 94) and the mean off-diagonal correlation \approx0.025 also match. The \beta=4 numbers in the prose (line 96) match outputs/summary.csv. The figure’s plotted ratios are exactly the table columns.

Independent re-run. A fresh disorder seed (--seed 12345, 1000 samples) at N=8,10 gave std_m1/pred = 0.998, 0.997, relstd_m2/pred = 1.375, 1.543, kurtosis -0.086,-0.040, mean abs corr 0.025 — fully consistent. Note the M_2 ratio for N=8 moved from 1.52 to 1.38 between seeds: the M_2 ratio is a fourth-moment quantity estimated from 1000 samples and carries roughly \pm10–15\% statistical error of its own. The trend in the M_2 column is robust; the precise per-row values are not (and the entry already hedges appropriately).

What the tests do and don’t establish (scope). The self-averaging ratios are self-normalized: predicted_std_m1 is built from the empirically measured \sigma^2 of the same run, and the M_2 prediction uses \sqrt{2/D}. So the numerics test the structure of the claim — diagonal covariance, marginal near-Gaussianity, and the 1/\sqrt{D} self-averaging — but they do not test the absolute value of \sigma^2(W) against an independent path-integral prediction, and they do not test the weight-only dependence of \sigma^2 (only W=4 is run). This is fine for the entry’s purpose; I note it so the reader doesn’t over-read the agreement as a check of the large-N covariance formula itself.

A sharper reading of the M2 deviations (my main suggestion)

The entry explains the order-one M_2 excess (and its growth at low T) by saying the one-point functions become “more nonlinear functions of the random couplings, so the independent-Gaussian approximation is a more stringent test” (lines 90, 96). That is correct in spirit, but “independent-Gaussian” bundles two distinct assumptions, and the data let us separate them. I decomposed the measured \mathrm{Var}_J(M_2) from the saved xi arrays as \mathrm{Var}(M_2)=\underbrace{\tfrac{1}{D^2}\sum_a \mathrm{Var}(\xi_a^2)}_{\text{marginal / diagonal}}+\underbrace{\tfrac{1}{D^2}\sum_{a\neq b}\mathrm{Cov}(\xi_a^2,\xi_b^2)}_{\text{joint / off-diagonal}}, expressing each in units of the ideal 2\sigma^4/D (so the entry’s prediction is “diagonal =1, off-diagonal =0”):

N (\beta=1) relstd(M_2)/pred diagonal off-diagonal marginal kurtosis
8 1.52 0.96 1.36 -0.085
10 1.57 0.99 1.47 -0.033
12 1.41 0.99 0.99 -0.016
14 1.33 1.00 0.78 -0.014
16 1.29 1.00 0.66 -0.010
18 1.19 1.00 0.41 -0.009

The diagonal (single-string) part sits at essentially exactly 1.00 — i.e. the marginal distribution of each \xi_a already obeys the Gaussian \mathrm{Var}(\xi^2)=2\sigma^4 prediction to sub-percent accuracy. The entire excess is the off-diagonal term: a genuine connected cross-string 4-point correlation \mathbb{E}_J(\xi_a^2\xi_b^2)_c. A split-half test on the 1000 samples reproduces this off-diagonal value across disjoint halves (e.g. N=8: 1.46 vs 1.27), so it is real signal, not sampling noise — even though the linear correlations are at the noise floor.

The low-temperature run makes the point even more sharply (\beta=4):

N (\beta=4) relstd(M_2)/pred diagonal off-diagonal marginal kurtosis
8 2.32 0.79 4.57 -0.44
10 2.29 0.92 4.35 -0.22
12 2.68 1.01 6.18 -0.06

Here the diagonal part tracks 1+\kappa/2 with the (now sizeable, negative) kurtosis, which on its own would reduce the M_2 fluctuations below the prediction. The observed large enhancement is entirely the off-diagonal connected 4-point term, which dominates by a factor of several.

The upshot is a small but real refinement of the entry’s narrative: it is the independence half of “independent-Gaussian” that fails at finite N/low T, not the Gaussian half. The marginals stay Gaussian (or develop a slightly negative kurtosis); what grows is the joint connected correlation between \xi_a^2 and \xi_b^2 for strings that share fermions. Consequently, in the boxed result on lines 110–113, the diagonal-covariance assumption (line 104) actually holds exactly, and the term that is being neglected when one writes the \sqrt{2/D} coefficient is \tfrac{1}{D^2}\sum_{a\neq b}\mathbb{E}_J(\xi_a^2\xi_b^2)_c. At fixed \beta this off-diagonal contribution decreases with N (the \beta=1 column above), so the M_2 self-averaging conclusion and its 1/\sqrt{D} scaling survive; but the coefficient of \mathrm{relstd}(M_2) is not the universal \sqrt{2/D} at finite N, and at low temperature it can be several times larger. If the entry wants to be maximally precise, a half-sentence to the effect that “the M_2 self-averaging coefficient is renormalized by an order-one cross-string 4-point correlation that grows at low temperature, while remaining subleading in the 1/\sqrt{D} scaling” would capture what the numerics actually show.

Results (lines 100–121)

  • The two self-averaging statements (lines 108, 112) are the correct readout of the moment calculation. As noted, the M_1 statement is exact; the M_2 statement holds with the coefficient caveat above.
  • “The difference … is exponentially small in N for these observables” (line 114): correct for fixed fractional weight W=\alpha N, since \binom{N}{\alpha N} is exponentially large; the connected-4-point correction renormalizes the coefficient but not the exponential scaling.

Bottom line

The entry is correct and the supporting calculation is faithful and reproducible. Two things I’d encourage the author to consider folding in (both strengthen the entry rather than correct it):

  1. State that the diagonal covariance \mathbb{E}_J(\xi_a\xi_b)=\sigma^2\delta_{ab} is exact at finite N (Schur’s lemma on the irreducible \Lambda^W), which in turn makes the M_1 self-averaging result exact.
  2. Attribute the M_2 excess specifically to a cross-string connected 4-point correlation (the failure of independence), not to single-string non-Gaussianity — the marginals are Gaussian to sub-percent accuracy, and at low T they actually have negative kurtosis while M_2 fluctuations nonetheless grow.

I was able to run all the small-N checks I wanted within the fast regime; I did not push to larger N (the dense ED cost grows as 2^{N}), so the asymptotic decay of the off-diagonal term is inferred from the N\le18, \beta=1 trend rather than established at large N.

Appendix: where the M2 excess comes from, in terms of cumulants

This appendix records the precise reason the M_2 fluctuations exceed the ideal \sqrt{2/D} even though the diagonal covariance \mathbb{E}_J(\xi_a\xi_b)=\sigma^2\delta_{ab} is exact. The short version: the diagonal covariance is exact, but the collection \{\xi_a\} is not jointly Gaussian at finite N, and M_2 is sensitive to precisely that failure.

The 2-point function fixes only the disconnected part of the 4-point function

Work with orthonormal strings, so g_{ab}\equiv\mathbb{E}_J(\xi_a\xi_b)=\sigma^2\delta_{ab} exactly. Then \mathrm{Var}_J(M_2)=\frac{1}{D^2}\sum_{a,b}\mathrm{Cov}_J(\xi_a^2,\xi_b^2),\qquad D=\binom{N}{W}, which is built from the 4-point function. The 2-point function controls only its disconnected (Wick) part: \mathbb{E}_J(\xi_a\xi_b\xi_c\xi_d)=\underbrace{g_{ab}g_{cd}+g_{ac}g_{bd}+g_{ad}g_{bc}}_{\text{fixed by the 2-pt function}}+\underbrace{\kappa_{abcd}}_{\text{connected 4-pt cumulant}}. The Gaussian model is exactly \kappa\equiv 0. Nothing about the exact 2-point function forces this.

Symmetry constrains the 2nd cumulant but not the 4th

cumulant what O(N) symmetry says value at finite N
2nd: \mathbb{E}(\xi_a\xi_b) Schur ⇒ unique invariant on \Lambda^W ⇒ \propto\delta_{ab} \sigma^2\delta_{ab} (exact)
4th: \mathbb{E}(\xi_a\xi_b\xi_c\xi_d)_c=\kappa_{abcd} many invariants on \Lambda^W{}^{\otimes 4} ⇒ unconstrained \neq 0 (non-Gaussian)

“Gaussian” is the assumption that all cumulants above 2nd vanish — a strictly stronger statement than what Schur’s lemma delivers. The space of invariant 2-tensors is one-dimensional (just \delta_{ab}), so the 2-point function is pinned; the space of invariant 4-tensors counts the irreps in \Lambda^W\otimes\Lambda^W and is multi-dimensional, so \kappa_{abcd} is free. Exact diagonal covariance and finite-N non-Gaussianity are independent facts at different cumulant orders.

Plugging \kappa into Var(M2)

With g_{ab}=\delta_{ab}: - diagonal (a=b): \mathbb{E}(\xi_a^4)=3\sigma^4+\kappa_{aaaa}\Rightarrow\mathrm{Var}(\xi_a^2)=2\sigma^4+\kappa_{aaaa}, where \kappa_{aaaa}=(\text{marginal excess kurtosis})\times\sigma^4; - off-diagonal (a\neq b): \mathbb{E}(\xi_a^2\xi_b^2)=\sigma^4+\kappa_{aabb}\Rightarrow\mathrm{Cov}(\xi_a^2,\xi_b^2)=\kappa_{aabb}.

Hence \mathrm{Var}(M_2)=\frac{2\sigma^4}{D}\Bigg[\,1+\underbrace{\frac{\overline{\kappa_{aaaa}}}{2\sigma^4}}_{\text{marginal kurtosis}/2}+\underbrace{\frac{1}{2\sigma^4 D}\sum_{a\neq b}\kappa_{aabb}}_{\text{cross-string sum}}\Bigg]. This is exactly the diag_part + off-diag_part decomposition in the body. The marginal term is an average of a quantity that is genuinely \approx 0, so it stays \approx 0; the cross-string term sums \sim D^2 small cumulants, so even a per-pair \kappa_{aabb}\sim\sigma^4/D survives the 1/D prefactor and gives an O(1) correction. That asymmetry is why the excess lives entirely off-diagonal.

Marginal Gaussianity is not joint Gaussianity (the Wick diagnostic)

For jointly Gaussian mean-zero variables, \mathrm{Cov}(\xi_a^2,\xi_b^2)=2\,\mathrm{Cov}(\xi_a,\xi_b)^2. Since the right side is exactly zero for a\neq b, joint Gaussianity would force \mathrm{Cov}(\xi_a^2,\xi_b^2)=0. The data (N=14, \beta=1, 1000 samples) violate this:

overlap k=\lvert a\cap b\rvert \langle\mathrm{Cov}(\xi_a,\xi_b)\rangle/\sigma^2 2\langle\mathrm{Cov}^2\rangle/\sigma^4 (Wick pred.) \langle\mathrm{Cov}(\xi_a^2,\xi_b^2)\rangle/\sigma^4
0 -7\times10^{-5} 2.0\times10^{-3} 4\times10^{-4}
1 6\times10^{-5} 2.0\times10^{-3} -4.1\times10^{-3}
2 6\times10^{-5} 2.0\times10^{-3} +1.3\times10^{-2}
3 -2\times10^{-4} 2.0\times10^{-3} -3.0\times10^{-3}

The linear covariance is at the 1/\sqrt{S} noise floor with random sign (consistent with the exact \delta_{ab}). The Wick prediction is flat at \approx 2\times10^{-3} across all overlap classes — the tell-tale sign that it is pure sampling noise on a quantity that is really zero. The measured \mathrm{Cov}(\xi_a^2,\xi_b^2), by contrast, is ~6× larger at overlap 2 and varies systematically with overlap (zero for disjoint strings, nonzero for shared-fermion pairs), structure that noise cannot produce. So the Wick identity fails, and the failure is a genuine connected 4-point cumulant.

Two “Gaussian” statements are therefore distinct, and finite N separates them: - each marginal \xi_a is very nearly Gaussian — excess kurtosis \approx 0, equivalently the diagonal Wick identity \mathrm{Var}(\xi_a^2)=2\sigma^4 holds to sub-percent; - the joint vector (\xi_a)_a is non-Gaussian — the cross Wick identity fails, i.e. \kappa_{aabb}\neq 0.

These coexist because nearly-Gaussian 1D marginals do not imply a jointly Gaussian vector. In the entry’s \mathbb{E}_J(M_2^2) derivation, “\xi(a) is Gaussian” read as marginal Gaussianity correctly gives the diagonal terms \mathbb{E}(\xi_a^4)=3\sigma^4 (which check out), but the off-diagonal terms \mathbb{E}(\xi_a^2\xi_b^2)=\sigma^4 silently require the stronger joint Gaussianity (independence). That upgrade — from “marginally Gaussian + zero pairwise covariance” to “independent” — is exactly what finite N violates, and it is the entire source of the M_2 excess.

Physical mechanism

At leading order \xi_a\sim J_a, so distinct strings depend on independent couplings and \kappa=0. Beyond leading order (higher powers of \beta), \xi_a picks up multi-J contributions, and two strings that share fermions build them from overlapping couplings, generating \kappa_{aabb}\neq 0. The overlap-resolved table above confirms this directly — disjoint strings (k=0) have \kappa\approx 0, all the action is in the shared-fermion classes. Lower temperature shifts weight onto these higher-order pieces, which is why the off-diagonal part balloons to \sim 5 at \beta=4 while the marginals stay near-Gaussian (indeed develop a small negative kurtosis). At fixed \beta and large N the per-pair cumulant is N-suppressed faster than the pair count grows, so the bracket \to 1 and the ideal \sqrt{2/D} coefficient is recovered asymptotically.

Temperature scan: the off-diagonal cumulant is the temperature-sensitive piece

Holding N=14, D=1001 fixed (1000 samples, matched seed) and varying \beta isolates the temperature dependence:

\beta relstd(M_2)/pred diag part off-diag part marginal kurtosis
0.5 1.10 1.00 0.20 -0.01
1 1.36 1.00 0.86 -0.01
2 1.93 1.00 2.73 -0.00

The diagonal part is pinned at 1.00 and the marginal kurtosis stays \approx 0 at every temperature — single-string statistics are essentially Gaussian throughout. The entire temperature dependence is carried by the off-diagonal (cross-string connected 4-point) part, which collapses as the temperature rises: roughly \propto\beta^2 at small \beta (each doubling of \beta multiplies it by \sim 3–4). This matches the mechanism: the cross-string cumulant arises from the higher-order-in-J (\sim\beta^3 and beyond) pieces of \xi_a, which vanish as \beta\to 0 where the state approaches the trivially-Gaussian infinite-temperature limit. So at fixed N the controlling small parameter for the M_2 deviation is effectively \beta, not just 1/\binom{N}{W}, and the operator ensemble reproduces the coupling ensemble more faithfully at higher temperature.
